# Bundled network marks

`solana.svg` is the unmodified logomark downloaded from the official branding
page https://solana.com/branding, asset
https://solana.com/src/img/branding/solanaLogoMark.svg.

SHA-256: `3d3401109aa061dec40a8659f1847817a8e647f98de1e65e76e86a95bbe1f08a`.

It identifies the Solana message family, not a verified cluster, token, issuer
or program. It is compiled into Broker and served through an exact static
route. No runtime asset fetching or filename-based filesystem reads occur.
The mark belongs to the Solana Foundation; use follows its brand guidelines.
